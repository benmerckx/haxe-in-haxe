Playground

The compiler below is the port, built from its own C output with Emscripten. Run type-checks your program and executes it with the port's Eval interpreter (--interp), the same interpreter that runs macros. Compile to HXB emits the compiler's binary module format, the port's first output target. Everything happens locally in a Web Worker; each run starts a fresh compiler instance. The runtime keeps 64-bit pointers, so this is a 64-bit WebAssembly module (memory64): it needs a recent Chrome, Edge or Firefox.

Download

		
One binary for Linux, macOS, Windows and the BSDs, on x86-64 and ARM64, built with Cosmopolitan. It carries the parts of the Haxe standard library it needs, so nothing else has to be installed.

Only the x86-64 Linux half has been tested. Code generation for JavaScript, C++, HashLink and the other targets isn't ported: the binary type-checks, runs programs with --interp and writes HXB.

	


	

		
Status

		
The goal is a close-to-line-by-line port of the Haxe compiler (haxe/src, pinned upstream commit b10fa6e) that keeps upstream's structure, branch order and data layout. Conformance is strict: for the same invocation, the port must write the same set of HXB modules, each byte-identical to what the OCaml compiler writes.

How it works

		
    
			
  1. Port. Each OCaml module in haxe/src has a Haxe counterpart in src/: records become classes, variants become enums, lists become arrays, with upstream's evaluation order preserved.
    2. 
			
  2. Type itself. The port parses, types and filters its own source, the same pipeline that produces HXB.
    3. 
			
  3. Lower to C. A small backend (backend/, also Haxe) lowers the typed program to C. Ints and floats are unboxed, generics are erased with boxing at the boundaries, virtual calls go through dispatch tables, and structural field access uses inline caches.
    4. 
			
  4. Runtime. About 3,000 lines of C: a precise generational copying GC with a shadow stack, UTF-16 strings, arrays with unboxed element kinds, and exceptions on setjmp. The standard library is mostly written in Haxe over a few native primitives, including the regular-expression engine.
    5. 
			
  5. Compile the C. tcc compiles the 16 MB file in under a second for development, gcc -O2 builds the fast native binary, cosmocc the portable one, and Emscripten the WebAssembly on this page.
    6.

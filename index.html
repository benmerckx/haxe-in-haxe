Haxe in Haxe

A port of the Haxe compiler from OCaml to Haxe. A C backend (hxc) compiles it to a native binary, or to WebAssembly for the playground below.

Playground

Run type-checks and runs the program with --interp. Compile to HXB writes an HXB archive. It runs locally as 64-bit WebAssembly, which needs a recent Chrome, Edge or Firefox.

Download

		
Builds of the latest commit on main, with the standard library included:

		
    
			
  • Linux: x86-64, ARM64
    • 
			
  • macOS: x86-64, ARM64
    • 
			
  • Windows: x86-64
    • 
			
  • One file for all of the above (Cosmopolitan): haxe-in-haxe.com (licenses)
    • 
		


haxe-in-haxe -cp src --main Main --interp
haxe-in-haxe -cp src --main Main --js out.js

		
It takes the same arguments as haxe. The Linux and macOS builds are compiled with zig cc; set HAXE_STD_PATH to the std directory in the archive. The Windows build and haxe-in-haxe.com are the Cosmopolitan build, which is slower (about 1.6× the time of the native builds on large compiles) and carries the standard library inside. All files: nightly release.

	


	

		
hxc for other programs

		
The C backend is also available as a Haxe target through the hxc haxelib package: Haxe types the program and writes HXB, hxc turns it into C, and a C compiler builds it. See hxc/haxelib/README.md.

	


	

		
Status

		
The port follows upstream (haxe/src, commit 995a7d1) module by module. For the same arguments it should produce the same output as the reference compiler; this is tested for:

		
    
			
  • HXB output: 279 of 279 conformance cases (and the 7 the reference rejects), 66 of 66 macro cases;
    • 
			
  • every target (JS, Lua, Python, PHP, Neko, HashLink, HL/C, JVM, C++, SWF) and --xml/--json, with a differential fuzzer and upstream test projects;
    • 
			
  • --interp, display requests, the compilation server and the Eval debugger;
    • 
			
  • upstream's target-independent CI job (unit, misc, threads, tink_core, hxcoro), which passes with the native build.
    • 
		

		
Details: test/TESTING.md.
